# AK Core Mission Control V4

Renovación visual integral sin eliminar ni mover módulos y sin modificar lógica de negocio.

## Cambios
- Shell Mission Control con sidebar, topbar y contenido de nueva generación.
- Dashboard con hero operativo y jerarquía más clara.
- Tarjetas KPI, tablas, inputs, botones y paneles unificados.
- Fondo técnico, profundidad, iluminación y microanimaciones discretas.
- Se conservan Planes, Servicios, Agrícola, Camión, DSG y todas las rutas actuales.
- Registro npm forzado al registro público.

## Instalación
Copiar todo el contenido sobre `autokeys-lab`, hacer commit y push. En Vercel: Redeploy + Clear Build Cache.

No requiere SQL.
